# MagicExpansion 1.1.17

This maintenance release hardens MagicExpansion resource generators and fixes a
Paper 1.21.11 One Block tile-state transition failure found during native
validation. Existing item and research IDs, persistent keys, recipes, quantities,
energy costs, machine rates, material-selection probabilities and shop identities
are unchanged.

## Resource generator stability

ResourceMachine and ResourceRandomOneMachine now handle an empty or unavailable
recipe list by idling safely instead of indexing the first recipe unconditionally.
This ports the relevant upstream guard while retaining the Legacy fork's saved
pending-output handling.

The native machine audit exercises every configured resource generator with both
empty and unavailable recipe lists for four ticker calls, confirms inventory and
energy stay unchanged, restores the original recipe list and verifies normal
production resumes. This removes a verified exception path that could otherwise
cause repeated ticker failures and temporary Slimefun machine pauses.

## One Block tile transitions

Origin One Block now safely retires an existing tile block before a different tile
type is replaced with a sculk shrieker on affected Paper builds. The compatibility
path is limited to the failing transition; ordinary replacements and same-material
tile replacements keep their existing behavior.

Regression coverage includes bed and chest transitions into sculk shriekers,
reverse and non-tile controls, Slimefun identity retention, and same-type chest
inventory and persistent-data preservation. The selectable material pools and
their probabilities are unchanged.

## Validation

The 1.1.17 source is validated through the repository's clean build, unit, API and
native runtime gates. The release candidate passed all 261 unit tests and the full
MagicExpansion item/machine audits on Paper 1.21.11, Paper 26.2, Paper 26.3 and
Purpur 26.3. Each native target includes 72 missing-recipe guard checks and 37
normal resource-generator transactions, plus One Block, Page Chest, generator,
power-relay, stacked-vivarium and item-catalog checks.

The exact candidate was also exercised against published Slimefun Legacy 4.1.76 on
Paper 1.21.11 for the focused machine and One Block/container probes.

Automated verification covers the exercised server API and persistence paths. It
does not establish crash-atomicity for arbitrary third-party storage, every
historical world, or live-client rendering. Folia support is not promoted by this
release.

## Upgrade

Stop the server normally and retain a complete backup of worlds and plugin data.
Replace the previous MagicExpansion JAR with `SF_MagicExpansion1.1.17.jar` and keep
`plugins/magicexpansion/`, shop files, Black Market state and player receipts.
Start normally and do not use `/reload`.
