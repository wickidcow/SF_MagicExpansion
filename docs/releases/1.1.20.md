# MagicExpansion v1.1.20 — Water Cloud safety, config, and 26.3 compatibility

Distinct immutable addon release based on the maintained v1.1.19 line.
**No automatic historical data migration or storage rewrite.** Existing items,
Slimefun IDs, typed PDC, Water Cloud XP, Black Market offer receipts, inventory
contents, recipes, costs and machine rates remain the compatibility contract.

## Fixes since v1.1.19

- **Water Cloud fishing:** keep paid catch velocity finite when the hook and
  angler are coincident, vertically aligned, unusually far apart, or coordinates
  are non-finite. Prevent invalid normalization from interrupting a legitimate
  bait-paid catch. Existing positive-distance trajectories retain their speed.
- **Fishing foundation (not automatically enabled):** deterministic Water Cloud
  hook math and one-shot cast session registry cover stale callbacks, timeout,
  player logout and shutdown in unit tests. The alternate fishing state machine
  is not yet registered in gameplay; standard fishing is unchanged.
- **Presentation:** use Adventure text for map feedback, shop editor status and
  gradient fireworks titles while preserving their prior colors and visibility.
- **Configuration:** read bundled YAML with Java's standard UTF-8 support.
- **Build:** checksum-verified Maven 3.10.0 and stable Maven plugins, canonical
  Java 21 raw JAR, Paper/Purpur 1.21.11 and 26.2 source builds plus stable
  Paper 26.3 API checks.

## Required distribution checks

The exact green-master publisher requires a successful in-repository master push
build, canonical same-run raw plugin JAR, a unique official SHA-256 digest,
Java 21 class validation and plugin.yml identity. Pre-existing tags and
release assets cannot be retargeted, deleted or overwritten. The official
standalone release is not valid until GitHub publishes v1.1.20 and confirms
that raw JAR digest and source SHA.

Native Paper/Purpur Black Market and full-stack acceptance runs are required
where available. Such synthetic/disposable CI tests cannot prove historical
AlbionMC player inventory rollback, cross-region Folia correctness, or every
fishing-plugin coexistence scenario. Those live-world behaviors are **not
claimed tested**.

## Installation and acceptance

1. Stop the server and back up worlds, Slimefun player data, saved Black
   Market/shop receipts, configs and inventories.
2. Replace the old MagicExpansion plugin with exactly one raw
   `SF_MagicExpansion1.1.20.jar`; do not install source or CI ZIP artifacts.
3. Start Paper/Purpur and check startup logs, Water Cloud rod/lure IDs, XP/PDC,
   Black Market offers and historical purchase receipts.
4. Test ordinary/paid/special fishing catches (including near-zero-distance
   hook trajectories), precisely one lure debit per paid catch, output amount,
   full-inventory payout fallback, disconnect/rejoin, and restart.
5. Verify prior editor messages and fireworks titles still render appropriately.

Old v1.1.19 and earlier GitHub tags/assets remain immutable. This release does
not modify Slimefun-Legacy core, the v81 addon ZIP, or SlimefunUnified.
