MagicExpansion **1.1.11** incorporates the coordinate-safe rare-fishing privacy changes already merged to master after 1.1.10.

- Public rare, super-rare and Fish Emperor catch announcements are **disabled by default**, including on servers with older configuration files that have no announcement keys.
- Precise player coordinates are no longer included in public catch announcements by default. Showing the world and X/Y/Z publicly requires **both** `fishing.announcements.enabled: true` and `fishing.announcements.show-coordinates: true`.
- Optionally send the angler a private congratulatory notice (`fishing.announcements.notify-player: true` by default) without revealing their location.
- `/magicexpansion reload fishing` applies updated fishing settings without a full server restart.
- Tests cover defaults, disabled public broadcasts, private messages, explicit public/coordinate opt-in and unchanged fish catch/reward behavior.
- Retains all **1.1.10 Black Market restart-safe purchase receipts and trade persistence fixes**, existing configs/persistent records, Slimefun item IDs, recipes, fish metadata, rewards, shop/command behavior, English descriptions and Java 21 bytecode compatibility.
- The public JAR remains compatible with Minecraft **1.21.11+**, including Paper/Purpur 26.3. GuizhanLib remains optional.

**Upgrade:** Back up the `plugins/magicexpansion` folder, especially the `black_market` subfolder containing purchase receipts. Replace the previous JAR rather than installing both. If you want public rare-catch messages, explicitly opt in using the new fishing announcement keys. Do not enable `show-coordinates` unless the server deliberately wants to share player locations.

**Scope:** This version adds no new location telemetry or database schema migration. It changes message privacy defaults only. The existing caveat for a process crash between purchase-receipt persistence and Black Market reward delivery still applies.

Canonical release JAR: `SF_MagicExpansion1.1.11.jar`. Do not distribute the versioned artifact until GitHub Actions tests and release checks pass.
