MagicExpansion 1.1.8 brings upstream Build 93 / Release 13 into the maintained English fork.

- Updated Starfall Judgment with projectile reflection, configurable Blazing Slash and Arcane Blast damage, and Shadow Blink effects. Added recursion protection, cancellation/protection checks, and reliable effect cleanup.
- Improved full-storage handling and partial cargo imports while preserving large counts, typed item data, reserved slots, and unreadable records.
- Reworked 446 English language entries: meaningful lore, readable names, fishing guidance, crop warnings, machine functions, controls, and historical notes. Corrected food, hologram-eraser, and sword descriptions against the implementation.
- Preserved item/research IDs, persistent keys and types, recipes, machine rates, and existing shop data. The historical final-rod identifier remains unchanged; its displayed name and lore are English.

Install the raw **SF_MagicExpansion1.1.8.jar** asset. It is built against Paper 1.21.11 and the checksum-verified Slimefun Legacy 4.1.61 API, with Java 21 bytecode. Java 25 is used to build and test it.

Verification: 76 tests passed without failures, errors, or skips; compilation passed against Paper 1.21.11, 26.2, and the pinned 26.3 API. The same tests also passed against Slimefun Legacy 4.1.66. A separate Paper 26.3 beta 143 server check with Slimefun 4.1.66 verified cargo metadata, sword event behavior, shop preservation, and a second server boot.

Deprecation audit: the updated sword has no compiler deprecation warnings. The rest of the inherited plugin still uses deprecated APIs, including legacy text, block storage, energy access, and item serialization. These remain visible in build output; this is not a claim that the entire plugin is free of deprecated APIs. Existing storage formats were retained for saved-data compatibility.

The server checks use controlled fixtures, including a player facade. They do not establish live-client combat, every historical world, crash atomicity, or concurrent-transfer behavior.
